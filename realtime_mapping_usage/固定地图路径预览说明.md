# 固定地图 A/B 路径预览

## 使用

1. 保持原来的 `start_fixed_map_relocalization.sh` 运行，并确认三维地图与实时点云重合。
2. 另开一个 Ubuntu-22.04 终端运行：

   ```bash
   bash /mnt/d/未来机器人/realtime_mapping_usage/start_fixed_map_path_preview.sh
   ```

3. 浏览器打开 `http://localhost:9880`，选择“使用实时 A”，在浅色可通行区域点击 B。黄线是规划结果。每次点 B 都使用当时的实时起点重新规划。
4. “手选 A”仅用于离线选点演示，不代表车辆真实位置。路径起点和终点必须处于膨胀后连通的可通行区域。
5. 定位超过 2 秒不更新时拒绝实时起点规划。旧路线是规划时的快照，车辆手动移动后需要重新点击 B，不自动跟随或执行。

程序启动时只绑定本机 `127.0.0.1:9880`，只读订阅 `/tf`；没有任何 LCM 发布器、CAN 或运动控制模块。它与重定位程序分开运行，关闭网页服务不会修改原地图或停止雷达。若端口已被占用，先确认是否已有本工具运行，避免重复启动。

## 来源与范围

- 固定代价地图：`D:\未来机器人\reconstruction_20261017_113920\raytrace\global_costmap.lcm`。
- 原地图坐标为上次建图的 odom，本工具只将这一静态文件的坐标名称标为 map，数值和原点不改变。当前运行中的 odom 则通过实际重定位 TF 转换到 map。
- 实时起点是 `inverse(T_odom_map) @ T_odom_mid360` 得到的雷达投影，尚未加入雷达/底盘安装外参。
- TRACER 用户手册第 6 页参数表和第 34 页尺寸图确认底盘长 702 mm、宽 610 mm。规划采用外接圆半径约 0.465 m，另加 0.10 m 余量及栅格几何补偿。这只包含手册底盘；外露支架或设备更大时，启动时用 `--length`、`--width` 指定实际整车尺寸（米）。
- 仅零代价格确认为候选可通行，未知区域和非零代价格均阻断。基于库内 A* 计算，检查对角穿角；必要时退回四邻接搜索，不接受穿越障碍角点的路线。
- 底盘外接圆策略较保守，可能拒绝实际可通过的窄通道。实际原地转向、雷达偏移、整车高度、动态障碍、制动与控制反馈未验证。
- 静态 CostMapper 的原始高度/爬越参数不是 TRACER 实车标定值。路径显示成功不证明整车可以自动安全执行该路线，下一阶段应重做通过能力参数和底盘外参标定后再接控制。
