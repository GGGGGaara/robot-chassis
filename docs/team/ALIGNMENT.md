## 可以直接发给队友

我们已把 MID-360 / FAST-LIO2 建图后端、重定位、点云适配、三维模型保存和 Nav2 纳入 `tracer_bringup` 的统一 ROS 2 启动。对外统一使用 ROS 2 话题、TF、action；建图内部仍是 DimOS/LCM，不是已经完成原生 ROS 2 重写。输入目标按发起任务时底盘当前位置和朝向解释：前进 / 左移，单位米。当前重点是环境复现、RViz 可视化和接口对接，不需要重新安装整套 ROS 或另写一套导航。

你先运行独立可视化示例，确认 `/map`、`/mapping/global_points`、`/plan`、`/lio/odom`、TF 能显示。该示例是合成数据，不运行 Nav2 控制，也不代表实车到达成功。之后接入已有建图数据，保持 TF 唯一发布者与现有安全控制链路。真实 A→B、尺量距离和 CAN 长期稳定性仍待现场验收。

## 分工建议与交付界面

| 工作 | 建议负责方 | 交付物与完成条件 |

| Humble / RViz / 示例组件 | 队友 | 快速开始跑通；截图 + doctor 报告 + smoke 报告 |

| 坐标任务与建模联动 | 双方接口联调 | 输入前进 1m / 左移 0m；规划和模型更新均可独立观测，目标在任务开始时冻结 |
| CAN / 控制模式 / 反馈稳定性 | 实车负责人 | 无模式切换、连续零速与故障注入记录，定位通信间断根因 |
| 实车 A→B 与障碍测试 | 双方现场 | 尺量距离、短时方向 / 停车、静态 / 动态障碍、到点停止证据齐全 |

上表是按职责建议分工，没有替任何成员认领任务。团队每次同步记录：分支 / commit、环境、自检结果、变动接口、阻断项、下一步；不要只说“Nav2 能跑”或“地图重合”。

## 推荐里程碑

1. **M1 环境对齐**：队友在无设备时跑通独立示例；无需复制本机虚拟环境。
2. **M2 数据接入**：后端发布真实话题，RViz 确认坐标系、米制和时间戳；本机 Nav2 与队友 Nav2 二选一启动。
3. **M3 离线导航闭环**：使用隔离回放 / 虚拟 CAN，记录路线、停止和模型落盘；不回放控制命令到实车域。
4. **M4 实车验收**：重新连接、定位与米制核验、通信稳定性、短时前进 / 左转、停车，再做短距离 A→B；15m 只是软件路径上限，不是已完成 15m 实车测试。
